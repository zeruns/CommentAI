## ✨ Features

- 🎯 **Multiple Working Modes**
  - Fully Automatic Mode: AI generates and publishes directly
  - Manual Review Mode: Generated reply requires admin approval before publishing (recommended)
  - Suggestion-Only Mode: Only shows suggestions, never auto-publishes

- 🌐 **Multi-Platform AI Support**
  - ✅ [Alibaba Cloud](https://www.aliyun.com/minisite/goods?userCode=jdjc69nf) Bailian (Tongyi Qianwen Qwen)
  - ✅ OpenAI (ChatGPT)
  - ✅ [DeepSeek](https://platform.deepseek.com/)
  - ✅ [Kimi](https://platform.moonshot.cn/) (Moonshot AI)
  - ✅ [SiliconFlow](https://cloud.siliconflow.cn/i/hSviAP2x): a one-stop cloud platform aggregating top-tier LLMs
  - ✅ Custom OpenAI-compatible endpoints

  > 🔗 **Recommendations & Introduction to Major AI LLM API Platforms:** [https://blog.zeruns.com/archives/947.html](https://blog.zeruns.com/archives/947.html)

- 🧠 **Context Awareness**
  - Reads the article title and summary
  - Analyzes the parent comment (reply scenarios)
  - Generates personalized replies based on context

- 🔒 **Security & Protection**
  - Built-in sensitive word filtering
  - API call rate limiting
  - Prevents spam comment triggers
  - Only replies to already-approved comments
  - Moderates comment content and filters violations

- 🎨 **Transparent Display**
  - Optional AI indicator (e.g. 🤖 AI-assisted reply)
  - Complies with ethical transparency principles

- 📊 **Polished Admin Panel**
  - Visual moderation queue
  - One-click publish / reject / regenerate
  - Statistics dashboard
  - Batch operation support
